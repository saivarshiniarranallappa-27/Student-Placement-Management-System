# Student Placement Management System

## Overview
A web-based Student Placement Management System developed using Python Flask and SQLite. The system helps students apply for companies and allows administrators to manage placement activities.

## Features
- Student Registration and Login
- Admin Login
- Company Management
- Apply for Companies
- View Applied Companies
- Application Status Tracking

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Project Structure

Student-Placement-Management-System/
│── app.py
│── requirements.txt
│── placement.db
│── static/
│── templates/
│── uploads/

## Installation

```bash
git clone https://github.com/saivarshiniarranallappa-27/Student-Placement-Management-System.git
cd Student-Placement-Management-System
pip install -r requirements.txt
python app.py
```
